# Project overview

This document has several heading levels. The outline shows them in the same order as the reader.

## Setup

Install the command-line tool, then open a Markdown file.

### Quick start

Run `folio notes.md` from the folder that contains your notes.

> Heading levels can skip numbers. Folio lists a heading under the nearest preceding heading at a shallower level.

## Reading notes

The reader preserves links, language highlighting, and tables.
