# A little room to read.

Markdown deserves a quiet window. **Folio** opens your words already formatted, with a simple editor whenever you need it.

## Three ways in

| From | Action |
| :--- | :--- |
| Finder | Select a Markdown file and press **Space** |
| Desktop | Double-click to open in Folio |
| Terminal | `folio notes.md` |

## Make yourself at home

- [x] Read first, edit when you want
- [x] Keep your files right where they are
- [ ] Write something worth keeping

> Simplicity is the result of deciding what matters.

### A small example

```swift
let message = "Hello, Folio."
print(message)
```

Use **⌘E** to edit, **⌘S** to save, and **⌘F** to find a word.
