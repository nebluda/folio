# Folio 0.1.2

- Use the Table of Contents toolbar button or **⇧⌘O** to show a collapsible outline. Choose a heading to jump to it, or use the arrow keys to navigate and expand groups.
- Folio prepares the next reader window in the background and colors code as it comes into view in large documents.
- Finder Quick Look reuses its renderer and limits syntax coloring for large files. The preview still shows all code.
- Added repeatable benchmarks for the reader and system Quick Look, plus WebKit checks for heading navigation, offscreen tables, and code highlighting.

On an Apple M1 Pro, the final warm app benchmark opened the generated 1 MB varied-code fixture in a median 638 ms, down from 1,068 ms in the preceding build. In the real Finder panel, the same fixture reached first meaningful paint about 22% sooner in cold extension trials and 31% sooner in warm trials. [Benchmark results and methodology](../VALIDATION.md#follow-up-profiling)

Folio supports macOS 14 and later. The app and Quick Look extension are ad-hoc signed. For a local build and installation, follow the [README](../../README.md#build-and-install).
