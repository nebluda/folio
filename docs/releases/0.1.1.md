# Folio 0.1.1

Table columns now preserve readable words in both the app and Finder Quick Look. Long descriptions wrap to leave room for short labels, fixing headers and names being squeezed into one or two characters per line.

Wide tables still expand beyond the normal prose width. If the columns cannot fit, the table scrolls horizontally without widening the document. Compact numeric columns continue to leave the remaining space for descriptions.

Includes eight WebKit layout regression scenarios covering narrow and wide windows, zoom up to 200%, light/dark appearance, inline code, long URLs, and many-column tables.

The download contains Folio.app with its Quick Look extension and bundled CLI. Requires macOS 14 or later on Apple Silicon. This prototype is ad-hoc signed and **not notarized**; macOS may block a downloaded build. Building locally remains supported using the README instructions.

Quit Folio before replacing an installed copy. Launch the updated app once and close/reopen any existing Quick Look panel to load the new renderer.
